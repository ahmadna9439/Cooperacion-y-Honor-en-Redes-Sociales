## 📖 About This Application

This software helps users study patterns of cooperation and honor within social media groups. It processes network data to show how people interact and build trust online. You can view connections, identify influential users, and see how information spreads across platforms. Researchers and network analysts use this tool to understand human behavior in digital spaces.

## 🚀 Getting Started

Launch the app from your Start menu or desktop icon. The application opens to a dashboard view. You see a sidebar with navigation tabs and a main workspace for your network maps. 

To load data:

1. Click the File menu at the top left of the window.
2. Select Open.
3. Locate your social media record file.
4. Click Open to import the data.

The software maps out your network. Small dots represent users. Lines between dots show connections or cooperative interactions. You can zoom in or out using your mouse wheel.

## 🔍 Using the Features

### Viewing Network Connections
Select a dot to see individual profile details. The sidebar displays user stats, such as how many connections they have and their honor score. The honor score represents the reliability of the user within the network based on their past actions.

### Running Simulations
You can test how information or trust spreads through your network. 

1. Click the Simulation tab.
2. Choose a start point by clicking a dot.
3. Click the Run button.
4. The software highlights which users receive the information next. 
5. Use the speed slider to slow down or speed up the visualization.

### Saving Your Work
The application saves your current project automatically. You can also save a snapshot of the visual map as an image file. Click Export to choose between saving your data as a project file or saving your map as a picture.

## ⚙️ Settings and Preferences

Adjust how the software looks and behaves in the Settings menu.

- Theme: Toggle between Light and Dark mode to reduce eye strain.
- Data Updates: Set how often the software checks for new social media data.
- Export Folder: Choose where the app saves your images and report files.

If the software runs slowly, go to the Performance tab and enable Low Graphics Mode. This lowers the visual detail of lines and dots but makes the map easier to handle on older computers.

## ❓ Frequently Asked Questions

What should I do if the app crashes?
Restart the application. If the problem continues, delete the app and download the installer again from the main link.

Can I open multiple files at once?
This software handles one project file at a time to ensure memory stability. Save your current work before opening a new file.

Where does the data come from?
The software processes files provided by the user in standard text or spreadsheet formats. You must gather your own social media data files first.

Does this software connect to my personal accounts? 
No. This tool processes data files you load manually. It has no access to your private social media logins or passwords. It remains entirely offline unless you choose to update network data through your browser.

## 🛠️ Troubleshooting

If the map fails to load, check the data file format. The software requires a file with columns for user names and connection types. Ensure there are no empty rows or broken links in your file. 

If text appears blurry, adjust your Windows display scaling settings to 100%. Right-click your desktop, choose Display settings, and look for the Scale and Layout section. 

Keep your graphics drivers current through the Windows Update tool. Modern visual software relies on these drivers to show detailed network maps without lag. For further help, visit the project page for common community answers.
